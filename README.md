# MAKAIRA :: Connect Module for Shopware 6 
[![License](https://img.shields.io/badge/license-GPLv3-green.svg)](LICENSE) [![Packagist Version](https://img.shields.io/packagist/v/makaira/shopware6-connect)](https://packagist.org/packages/makaira/shopware6-connect) 
![Static Badge](https://img.shields.io/badge/makaira-connect--module-yellow.svg)

This module allows you to connect your Shopware store with Makaira in order to use headless functionalities like CMS, Search, Recommendation, Personalization.

---
## Installation

Depending on you Shopware 6 version you need setup a specific connect version.

#### Shopware 6.5 and higher
```
composer require makaira/shopware6-connect:^2.0
```

⛏ Development is done in `stable` branch

---

#### Shopware 6.0 to 6.4
```
composer require makaira/shopware6-connect:^1.0
```

⛏ Development is done in `1.x` branch
